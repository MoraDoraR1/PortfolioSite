# Game Designer Portfolio 작업 현황

- 작성일: 2026-09-08
- 작업 파일: `outputs/portfolio.html`
- 현재 단계: 페이지 기본 구성 완료 / 포트폴리오 자료 업로드 전
- 공개 배포: 보류

## 1. 현재 진척도

### 완료

- 단일 HTML 기반 포트폴리오 랜딩 페이지 구성
- 데스크톱·태블릿·모바일 반응형 레이아웃 적용
- iOS 안전 영역과 모바일 스크롤 동작 대응
- 본문 Pretendard 계열 폰트와 목차·번호용 도트 폰트 적용
- 헤더 좌측 타이틀을 `GAME DESIGNER PORTFOLIO`로 변경
- 헤더 목차를 다음 순서로 연결
  - INTRO
  - PROFILE
  - RESUME
  - ESSAY
  - PORTFOLIO
  - GAME LOG
- INTRO에 소개 문구와 프로필 사진 적용
- PROFILE에 다음 정보 반영
  - 사진과 기본 프로필
  - 생년월일과 연락처
  - 키워드와 관심 장르
  - `01 학력`, `02 수상`, `03 병역` 요약 카드
  - 도구별 실제 아이콘과 사용 경험 툴팁
- RESUME을 다음 두 항목으로 재정렬
  - `01 프로젝트 경험`
  - `02 직무교육 경험`
- 프로젝트별 기간·인원·역할·기여 내용 정리
- 출시 전 상태와 다운로드 수를 나중에 수정할 수 있는 문구 적용
- 자기소개서 내용을 ESSAY 화면에 구성
- GAME LOG에 게임별 타이틀 이미지와 분석 내용 적용
- PROFILE부터 GAME LOG까지 하나의 가로 토글·스와이프 화면으로 통합
- 이전·다음 페이지 버튼과 키보드 좌우 방향키 이동 지원
- 중첩된 세로 스크롤을 제거해 페이지 전체 스크롤로 통일

### 현재 들어가 있는 임시·변경 예정 정보

- 컴스톡 출시 상태: `출시 예정 · 출시 후 업데이트`
- 컴스톡 다운로드 수: `출시 후 업데이트`
- PORTFOLIO 프로젝트는 현재 텍스트 요약 카드만 존재
- 프로젝트 기획서·발표 자료·플레이 영상은 아직 연결하지 않음

### 보류한 작업

- 포트폴리오 문서·영상 업로드
- 프로젝트 상세 보기 화면
- 관리자 계정 로그인과 웹페이지 직접 편집 기능
- 실제 배포 및 공개 URL 생성
- 공개 전 개인정보 노출 범위 최종 확인
- 실제 모바일 기기와 주요 브라우저에서의 최종 화면 검수

## 2. 다음 작업 목표

다음 작업에서는 PORTFOLIO 화면에 프로젝트별 증빙 자료를 추가한다. 프로젝트 카드는 핵심 내용을 빠르게 파악하는 요약 영역으로 유지하고, 문서와 영상은 별도의 상세 영역에서 열리도록 구성한다.

### 업로드 예정 자료

프로젝트별로 준비 가능한 자료만 선별한다.

- 기획서 PDF
- 시스템·콘텐츠 기획 문서
- 발표 자료 PDF 또는 PPT 이미지
- UI 목업과 와이어프레임
- 게임 플레이 영상
- 프로토타입 시연 영상
- 스크린샷과 GIF
- 다운로드 가능한 결과물 또는 외부 링크

## 4. 자료 전달 시 필요한 정보

각 자료와 함께 아래 내용을 전달하면 페이지에 정확히 반영할 수 있다.

1. 프로젝트 이름
2. 자료의 종류
3. 화면에 표시할 제목
4. 자료에 대한 한두 문장의 설명
5. 본인이 담당한 부분
6. 공개 가능 여부
7. 다운로드 허용 여부
8. 프로젝트에서 가장 먼저 보여줄 대표 자료

## 5. 권장 파일 구조

```text
outputs/
└─ assets/
   └─ portfolio/
      ├─ comstock/
      │  ├─ cover.webp
      │  ├─ planning-document.pdf
      │  ├─ gameplay.mp4
      │  └─ screenshots/
      ├─ tomorrow/
      ├─ dice-board-game/
      └─ space-design/
```

파일명은 영문 소문자와 하이픈을 사용한다. 같은 자료의 수정본이 여러 개일 경우 공개할 최종 파일만 업로드한다.

## 6. 문서·영상 적용 방식

### 문서

- 표지 이미지와 문서 제목을 먼저 표시
- 클릭하면 브라우저에서 PDF 미리보기 제공
- 필요한 경우에만 다운로드 버튼 제공
- PPTX나 DOCX 원본은 PDF로 변환한 공개용 사본 사용 권장
- 주민등록번호, 주소, 서명, 개인 연락처 등 민감한 정보는 업로드 전에 제거

### 영상

- 대표 썸네일과 재생 시간을 표시
- 자동 재생과 자동 음소거 영상은 사용하지 않음
- 사용자가 눌렀을 때만 재생
- 자막 또는 영상 내용을 설명하는 짧은 문구 제공
- 로컬 MP4를 사용할 경우 모바일 데이터 사용량을 고려해 용량 최적화
- 외부 영상 서비스를 사용할 경우 공개 범위와 임베드 허용 여부 확인

## 9. 완료 기준

- 각 프로젝트에서 대표 결과물과 본인의 기여가 명확하게 보임
- 문서와 영상이 모바일에서도 잘리지 않고 정상적으로 열림
- 페이지 이동 시 이중 스크롤이 발생하지 않음
- 공개하면 안 되는 개인정보와 내부 정보가 제거됨
- 출시 상태와 프로젝트 수치가 최신 정보로 표시됨
- 모든 링크·다운로드·영상 재생 동작을 실제 기기에서 확인함
